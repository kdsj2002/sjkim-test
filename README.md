# 🚀 스페이스 슈터 게임

로컬에서 실행할 수 있는 재미있는 HTML 기반 우주 슈팅 게임입니다!

## 🎮 게임 방법

### 실행 방법
1. `space-shooter.html` 파일을 웹 브라우저로 열기
2. "게임 시작" 버튼 클릭

### 조작법
- **← / →** (왼쪽/오른쪽 화살표): 우주선 이동
- **SPACE BAR**: 총알 발사

### 게임 규칙
- 빨간색 적을 처치하여 점수를 획득하세요
- 적과 충돌하면 체력이 감소합니다
- 체력이 0이 되면 게임 오버!
- 점수 100점마다 레벨이 상승합니다
- 레벨이 올라갈수록 적이 더 빠르고 강해집니다

## 🌟 게임 특징

- ✨ 부드러운 애니메이션과 파티클 효과
- 🎯 점점 어려워지는 난이도
- 💥 폭발 효과와 시각적 피드백
- 🌌 우주 배경과 별 애니메이션
- 📊 실시간 점수 및 레벨 표시

## 💡 팁

- 적의 이동 패턴을 파악하세요
- 총알을 아껴쓰지 마세요 - 계속 쏘세요!
- 레벨이 올라갈수록 적의 체력도 증가합니다
- 화면 가장자리를 활용하여 피하세요
