# sjkim-test

Python 프로젝트 템플릿

## 설명

이 프로젝트는 Python 기반의 애플리케이션입니다.

## 설치 방법

```bash
# 가상환경 생성
python -m venv venv

# 가상환경 활성화 (Linux/Mac)
source venv/bin/activate

# 가상환경 활성화 (Windows)
venv\Scripts\activate

# 의존성 설치
pip install -r requirements.txt
```

## 사용 방법

```bash
python src/main.py
```
